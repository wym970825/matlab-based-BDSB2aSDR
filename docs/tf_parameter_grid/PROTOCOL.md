# 400/600/800 kHz × 3/6/9/12 μs 参数选择实验记录

本轮补齐 400 kHz、800 kHz 的 3/6/9 μs 六个组合，各用同一带干扰半物理文件、PRN 11 完整跟踪 715 秒。600 kHz 的四档以及 400/800 kHz 的 12 μs 复用已完成记录。结论写入本目录的《参数选择报告.md》。接收机版本仍为 v0.2.0，本地实验分支为 `experiment/tf-bandwidth-edge-grid`，不推送远端。

## 控制条件

- 文件：`720_2700_50_1176_25_37p5_17p5.dat`，第 4 组，2700 / −50 dBm。
- 25 MHz、int16 交织 IQ、skip=0、单 PRN 11、串行跟踪、715000 历元。
- TF v1 复数 FIR，中心 −450 kHz，深阻带全宽为 400/600/800 kHz，每侧频域过渡 150 kHz，641 抽头，Kaiser β=5.65326。
- 幅度阈值继承原配置 192.73917883288581，尾部裕量 2 μs。
- `triangleSpanUs` 表示每个外侧过渡的总跨度 `2K/fs`，不是三角核半跨度。保持全权重平台半径 `D+P` 不变，`A=D+P+K`、`H=D+P+2K` 随 K 换算。
- 其余配置与历史 600 kHz / 12 μs 基线完全一致；执行前核对接收机源码内容哈希。
- 独立验证覆盖 400/800 kHz × 四档跨度 × 两个采样率（25/30.69 MHz）× 两种 IQ 位宽；辅助合成分量诊断与实际 RF 结果分别解释。

## 比较口径

先检查完整性、逻辑时间轴、REACQ、额外 INIT 和 S4 可用覆盖，再比较共同物理时间窗口的 C/N0 与 S4。不能通过删除失锁区间后只比较剩余均值来掩盖稳定性损失。

原生 C/N0 每 200 ms 更新，保存值包含当前与前一窗口；要求完整 400 ms 支持均有效 LONG，窗口起点不早于 150 秒，物理支持至少 99% 重合。另列边缘偏差不超过 2 个采样的严格子集。重捕获后的物理回退通过样本时间配对，不按数组下标硬配，也不插值。

S4 必须在原生更新时刻比较，完整 60000 历元窗口均有效 LONG。独立报告有限输出数、通过全窗口筛选数以及 12 组共同窗口数；去趋势 IIR 历史影响并不因 60 秒筛选严格消失。无逐点 S4 真值，因此差值 RMS 不能称为真值 RMSE，S4 变小也不能直接称为准确性提升。

共同窗口同时按全部 12 组、各带宽四档、同跨度三带宽、初始化后持续 LONG 的子集统计；所有两两配对保留供复核。600 kHz / 9 μs 是统一差值参考，不预设为最终优胜参数。Weil 峰值比从无 REACQ 记录中重构并核验；REACQ 记录另行核对 PLL 饱和保护及物理时间回退，不套用错误的 NH 相位锚点。

## 文件与复现

```matlab
setupPaths; addpath(fullfile(pwd,'tests'));
r = fullfile(pwd,'results','tf_parameter_grid','new_run');
run_tf_parameter_grid(r);
analyze_tf_parameter_grid(r,fullfile(r,'analysis'));
plot_tf_grid_candidates(fullfile(r,'analysis'));
```

两个输出目录须为新目录。驱动 `run_tf_parameter_grid.m` 包含独立验证、合成分量诊断、六次 30 秒短段及六次 715 秒完整实验。短段只用于检查配置与完整性，不评价尚未预热的 S4。完整实验原始 MAT/日志保留在本地 `results/`；最终报告附小型 JSON/PNG 证据与哈希清单。
