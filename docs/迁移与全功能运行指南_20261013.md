## 3. 运行环境

| 组件 | 用途与要求 |
| --- | --- |
| MATLAB | 使用完整 MATLAB 并完成许可配置。优先 R2026a；保留 R2024b 作为本轮 H0 短测的复现版本。 |
| Signal Processing Toolbox | `pwelch`、`fir1`、`kaiser`、`butter`、`filtfilt` 等，覆盖探针、TF 与闪烁处理。 |
| Communications Toolbox | 导航译码直接调用 `comm.CRCDetector`。只测跟踪不能验证导航依赖已经齐备。 |
| Parallel Computing Toolbox | 开启并行捕获和多星 `parfor` 时需要；串行可运行。 |
| Optimization Toolbox | S4 修正的联合门限拟合调用 `lsqnonlin`、`optimoptions`。 |
| Statistics and Machine Learning Toolbox | 同一 S4 拟合调用 `ncx2cdf`；接收机 PB 的 `norminv` 本身有 `erfinv` 替代路径。 |
| Python 3.9+ | Web UI 及本项目现有常规批处理只用标准库，无须 MATLAB Engine、Node.js 或 npm。Python 3.11/3.12 可作为固定部署版本。 |
| C 编译器 | 本机编译两个 MEX。Windows 已验证 MSVC 2022；Linux 使用对应 MATLAB 版本支持的 GCC。 |
| 浏览器、地图访问 | 浏览器可放在本地电脑；在线底图需要相应网络和百度 AK，离线静态图使用已缓存瓦片。 |

MATLAB Runtime 用于运行已经编译打包的应用；当前仓库通过 `matlab -batch` 运行 `.m`，并未提供这样的独立部署包，所以只装 Runtime 不满足现有入口。[MathWorks Runtime 说明](https://www.mathworks.com/help/compiler/matlab-runtime.html)

普通 `geoaxes/geoplot/geobasemap` 属于 MATLAB；Mapping Toolbox 不是本项目当前轨迹图的统一硬依赖。自定义地图功能应按实际调用另查。现有紫色—橘色插值已实现在 `batch/data1020_purple_orange.m`，无需为这一配色另复制 `dme_L5_Scintillation-v3`。[geobasemap 文档](https://www.mathworks.com/help/matlab/ref/geobasemap.html)

R2026a 在本机完成过算法、MEX 和绘图兼容验证，但启动阶段出现过崩溃；项目 Web runner 已有独立 preferences 和 Windows `r_wait` 路径。最近 H0 72 条短测实际使用 R2024b。新服务器先分别检查启动与算法，不把本机的启动问题当成所有 R2026a 机器都会出现的问题。见 [R2026a 兼容记录](r2026a_compatibility.md)。

资源配置建议：先用一个 MATLAB 进程、串行处理；内存按 32 GB 起步、64 GB 更适合多星并行与历史结果回放来规划，这属于容量规划值。20 MHz int16 IQ 为 **80 MB/s、4.8 GB/min**。多星各自读取 IF，优先本地 SSD/NVMe；当前并行池上限是 **6 workers**，设置更大的 `parMaxWorkers` 会被收敛到 6。现有主链未使用 GPU，增加 GPU 不会自动加速。

## 4. 路线 A：整体复制到 Windows 服务器或新电脑

1. 记录分支、HEAD、MATLAB 版本和原配置；待正在写结果的任务结束后复制其结果目录。
2. 复制 B2a 完整目录，包含 `.git` 和未跟踪程序。另复制六份 IF；需要 S4 时复制独立 S4 项目及其资源。
3. 在目标机安装 MATLAB、所需工具箱、Python、C 编译器；安装路径无需和原机器相同。
4. 目标机若继续使用相同 `F:\matlab-GNSSsdr\BDS\B2a`、`F:\Data\...` 路径，现有实验脚本的改动最少；换盘符则按第 6 节统一替换外部配置路径。
5. 进入项目根目录执行 `setupPaths`，编译/检查 MEX，再按第 8 节验收。
6. 通过 CLI 或本地浏览器连接服务器 Web UI，长任务不启动 MATLAB desktop。

目录复制可用 `robocopy /E /COPY:DAT /DCOPY:DAT /R:2 /W:1 /XJ`；这里不使用 `/MIR`，已有目标目录中的独立结果也能保留。输入文件做大小和 SHA-256 核对，原始 IF 与结果分别记录，避免把相同文件名当作相同数据。

如果不走网络仓库，也可以在源机生成 `git bundle create B2a-current.bundle --all`，目标机从 bundle clone 当前实验分支。**bundle 仍不包含未跟踪程序、被忽略的 IF/结果/密钥，必须另带。**

## 6. 路径和配置必须调整的地方

基础 MATLAB 模块由 `setupPaths.m` 相对自身定位，能随项目目录移动。**不要用 `addpath(genpath(projectRoot))` 添加整个项目**，避免把 `legacy/` 的同名旧函数加到当前路径。

| 位置 | 迁移处理 |
| --- | --- |
| 运行配置 | 修改 `filePath`、`fileName`、`outDir`，保留采样率、数据类型、IQ 顺序、门限、环路参数。 |
| 起始偏移 | 明确指定 `skipNumberOfBytes=0` 或真实偏移。`initSettings` 未覆盖时沿用历史 3005 秒偏移。 |
| Web 默认配置 | 更新 `config/ui_defaults.json`；它含旧机器的数据绝对路径。 |
| 旧结果/manifest | 重映射 `sourceFile`、`pbDir`、`tfDir`、`outputRoot`、`analysisDir` 等路径，以及回放所用 settings 中的路径。 |
| TF H0 外部程序 | `batch/data1020_tf_h0/*.m`、`launch.ps1`、报告生成程序内有固定 F 盘路径和 MATLAB 可执行路径。 |
| PB-S4 外部程序 | `data1020_config.m`、`data1020_navigation.m`、`data1020_main.m`、启动脚本含 B2a/S4/结果固定路径。 |
| S4 配置 | 用 cfg 覆盖 `receiverRoot`、`resultDir`、`outputDir`、资源位置；按当前条件保留已有 calibration 配置。 |
| 地图 | 配置 `baiduMapKeyFile`；复制卫星瓦片缓存，重新生成带新路径的瓦片 manifest。 |
| 新运行结果 | 给每次运行独立 `outDir/tag`；避免新服务器继续使用旧实验输出目录。 |

这批数据的频率设置尤其容易混淆：

| 实验 | 射频采样中心 | 接收机 `IF` | TF 原始 IQ 中心约值 |
| --- | ---: | ---: | ---: |
| 02 / HUR_1 | 1176.45 MHz | 0 Hz | −6.450195 MHz |
| 04 / 103330 | 1175.40 MHz | +1,050,000 Hz | −5.400391 MHz |
| 05 / 103801 | 1175.40 MHz | +1,050,000 Hz | −5.390625 MHz |

**“ZeroIF”文件名并不意味着 B2a 信号的 `settings.IF` 必定为零。** 对 04/05，B2a 标称载频与采样中心相差 +1.05 MHz。`Frontend.TF.centerHz` 使用原始复 IQ 的数字频率，不能填 1170 MHz，也不能再次叠加 `settings.IF`。TF 参数和图形界面没有完全对应：现有 Web schema 没有 TF 配置控件，TF 应通过 JSON/结构体入口指定。见 [TF 用法](upgrade_v020/USAGE.md)。

## 7. Windows 与 Linux 的启动方法

### Windows

先在 MATLAB 命令行配置本机 C 编译器并构建：

```matlab
cd('F:/matlab-GNSSsdr/BDS/B2a')
setupPaths
mex -setup C
build_mex
which correlateB2aMs_mex -all
which pulseBlank_core_mex -all
```

Windows 文件为 `.mexw64`；编译后的功能验收应在新 MATLAB 进程进行，避免已加载旧二进制或缓存“无 MEX”状态。项目也有纯 MATLAB 相关/消隐路径，MEX 是性能项；大数据迁移应把 MEX 验收列入完整部署。

无 MATLAB 桌面的批处理可用 PowerShell，`server_run.m` 指第 8 节按目标路径保存的外部运行程序：

```powershell
$b2aRoot = 'F:\matlab-GNSSsdr\BDS\B2a'
$b2aMatlab = 'C:\Program Files\MATLAB\R2024b\bin\matlab.exe'
$b2aArgs = '-wait -singleCompThread -logfile "results/deployment_run.md" -batch "server_run"'
Start-Process -FilePath $b2aMatlab -ArgumentList $b2aArgs -WorkingDirectory $b2aRoot -WindowStyle Hidden
```

MATLAB 路径按目标安装替换；R2026a 先进行 `disp(version)` 启动检查，再运行短测。本项目已知的 R2026a Windows 启动问题可使用 Web runner 的 `B2A_MATLAB_LAUNCH_MODE=r_wait`，见兼容文档。

Web 控制：

```powershell
$env:B2A_MATLAB = 'F:\MATLAB2026a\bin\matlab.exe'
python launch_b2a_ui.py --host 127.0.0.1 --port 8787 --no-browser
```

这里 `--no-browser` 仅禁止自动打开网页，不等价于禁止 MATLAB 绘图。服务器执行层仍要设置隐藏 figure、禁止打开百度浏览器；自动批处理优先使用显式配置的 CLI。

### Linux x86-64

MATLAB 应安装在该版本支持的 Linux 发行版上，编译器也按版本选择，不能直接复制 Windows MATLAB 安装目录或 `.mexw64`。[MathWorks 历史版本系统与编译器要求](https://www.mathworks.com/support/requirements/previous-releases.html)

核心 MEX 已有非 Windows 的 GCC 构建分支，相关器使用 SSE2；这里规划 x86-64，不把 ARM 服务器当成直接兼容目标。到目标机执行 `setupPaths; mex -setup C; build_mex` 后生成 `.mexa64`，再做数值验收。

```bash
cd /srv/gnss/B2a
/opt/MATLAB/R2026a/bin/matlab -batch "disp(version)"
nohup /opt/MATLAB/R2026a/bin/matlab -singleCompThread -nodisplay \
  -logfile results/deployment_run.md -batch "server_run" \
  > results/deployment_launcher.md 2>&1 &
```

`-batch` 是非交互执行入口；Linux 即使不显示图形也需要 MATLAB 所要求的系统图形库。保留正常 JVM/运行库，隐藏 figure 后导出 PNG；不要为省资源直接采用会影响所需功能的精简启动组合。[MATLAB Linux 启动文档](https://www.mathworks.com/help/matlab/ref/matlablinux.html)

Linux 的完整移植还需处理以下具体代码：

- `python/b2a_ui/matlab_runner.py::_matlab_clean_env`：目前构造的 PATH 是 MATLAB 与 Windows 系统目录，locale 为 `en_US`，也未传递 `MLM_LICENSE_FILE/LM_LICENSE_FILE`。POSIX 分支应保留目标机系统 PATH、有效 locale 及所需许可变量。先用直接 CLI 验证核心，不能只设置 `B2A_MATLAB` 就认定 Web runner 已移植完成。
- `batch/verify_data1020_recovered_chunk.py`：使用 `os.add_dll_directory`、`ctypes.WinDLL('kernel32')`、Windows `hdf5.dll`；属于结果校验辅助程序。Linux 可先以 MATLAB 读取/比较 MAT，或另适配此辅助脚本。
- `.ps1` 启动器、实验绝对盘符、文件名大小写、中文路径/字体、结果元数据路径需逐项调整。批处理不要调用服务器浏览器。

远程 Web 推荐仍监听 `127.0.0.1`，在本地使用 SSH 转发：

```text
ssh -N -L 8787:127.0.0.1:8787 user@server
```

然后本地浏览器打开 `http://127.0.0.1:8787`。网页中的 IF 路径指服务器磁盘，不是本地电脑磁盘。项目 HTTP 服务没有多用户鉴权体系，不将它当作已具备账户隔离的公网服务。地图另用 8765 端口时可单独转发，或下载生成的静态 PNG/HTML 在本地查看。
