## MATLAB 运行环境问题

本机 R2026a `parpool('local',4)` 的 worker 启动时访问冲突，退出状态 `-1073741819`。隔离 JobStorageLocation 和偏好目录仍复现，堆栈位于 MATLAB 的 `mwhomesessionmanager_impl` / `mwrecent_artifacts_service_impl`。无 DME 60 秒诊断因此自动回退到串行。

线程池能启动，但实际跟踪调用 MEX 时被 R2026a 拒绝；不能作为当前接收机的替代运行方式。没有修改 MATLAB 安装、用户既有偏好目录或全局并行配置。

完整五组采用已验证的 `C:/Program Files/MATLAB/R2024b/bin/matlab.exe`，仍为 4 个进程 worker。运行时版本变化已明确记录，实验 JSON 参数保持不变。MCP 单次调用会在 300 秒后超时，超时并不代表 MATLAB 计算已停止；长任务采用独立 MATLAB 进程执行并落盘日志。
