## 1. 必须先明确的频率、阈值与数据含义

### 1.1 400 MHz 暂按 400 kHz 候选开展设计，尚待单位确认

五组配置均为复数 IQ、采样率 25 MHz，有效离散基带区间为 [-12.5, 12.5) MHz。“总带宽 400 MHz、单边 200 MHz”无法在该 IF 数据上实现为局部陷波。它也不能通过把射频中心 1176.45 MHz 代入数字滤波器得到实现。

本报告为继续验证，**条件性采用总带宽 400 kHz、单边 200 kHz**，并增加 200、600、800 kHz 扫描；这不是对原始单位的最终确认。统一分别定义：

| 参数 | 含义 | 本轮值 |
|---|---|---|
| 中心频率 \(f_c\) | 相对于 IQ 数据零频的带符号频率 | 仿真 -450 kHz |
| FIR 阻带宽度 \(B_s\) | 要求深衰减的完整频带宽度 | 400 kHz，另测 600 kHz |
| FIR 单侧过渡带 \(\Delta f\) | 从阻带边缘到通带边缘的距离 | 150 kHz |
| IIR 带宽 \(B_{3dB}\) | 相对远端通带的完整 -3 dB 宽度 | 400 kHz |
| 三角窗时长 | 两端零值间的时间跨度 | 12 μs |

FIR 的 400 kHz 与 IIR 的 400 kHz **不是相同衰减规格**。比较时必须查看完整频响和脉冲总能量残留。

### 1.2 既有 RF 的干扰中心不是 0 Hz

对每组原始文件在文件时间 0、360、600 s 各读取 20 ms，采用 Welch PSD，围绕谱峰 ±400 kHz 对扣除中位谱底后的正超额功率取频率质心：

| 文件组 | 三次中心估计，kHz |
|---|---|
| 无 DME | 噪声中的谱峰不作为干扰中心 |
| 1350 / -50 dBm | -450.521，-450.570，-450.606 |
| 1350 / -60 dBm | -450.589，-450.630，-450.453 |
| 2700 / -50 dBm | -450.514，-450.502，-450.604 |
| 2700 / -60 dBm | -450.401，-450.508，-450.538 |

因此 v1 宜先配置约 -450 kHz，实际集成时可采用独立校准所得 -450.5 kHz；不宜默认 0 Hz。以上是短片段估计，并非信号源频率真值或整段稳定性证明。原始结果见 [rf_center_probes.json](../../results/tf_blanker_design/rf_center_probes.json)。

### 1.3 现有 PB 配置是幅度阈值

[pulseBlanker.m](../../channelCtrl/pulseBlanker.m) 中静态阈值的语义为幅度，检测功率时使用其平方。新公式应写为

\[
 m[n]=\mathbf 1\{|x[n]|^2\ge T_P\},\qquad T_P=T_A^2.
\]

| 组别 | 继承的幅度阈值 \(T_A\) | 新模块使用的功率阈值 \(T_P\) |
|---|---:|---:|
| 无 DME | 1288.1605785013 | 1659357.6760 |
| 四个 DME 组 | 192.7391788329 | 37148.3911 |

不能把 192.739 直接与 \(|x|^2\) 比较。dBm 仅在现有接收机标定规则下转换，不另造一个 ADC 单位到 dBm 的映射。捕获使用原配置的 Th_static，跟踪优先 Th_static_tracking；这五组中二者一致。

## 2. 三篇文献提供了什么，哪些是本方案的扩展

| 文献 | 与本任务直接相关的内容 | 本方案的使用边界 |
|---|---|---|
| Gao 等，2013，[1]，印刷页 566、Fig. 13 | Hybrid Blanking：时域检测脉冲，估计中心和持续时间，对脉冲附近数据 FFT，消除超过谱阈值的频点，再 IFFT 放回；另比较固定分段 FDAF | 支持“只在受扰时间和频率区域处理”的思想。本文提出的 FIR/IIR 支路混合、12 μs 三角窗，并非该文原算法的逐项复现 |
| Borio 等，2008，[2]，式 (7)–(15) | 实信号共轭零极点陷波、归一化自适应更新、检测后选择滤波/原始输出，以及 GNSS 相关器性能损失分析 | 用于理解零极点、检测与滤波解耦、相位和相关损失。不能直接把其面向实 CW 的双共轭陷波套到单侧复 IQ DME |
| Ferrara 等，2018，[3]，式 (1)–(2)，检测流程及 ANF 对比 | 在 IF 频谱中检测受扰频带，估计中心和带宽，配置单极点陷波；无检测时旁路 | v2 借鉴其谱检测和中心估计，**按本任务要求固定带宽**。该文会估计带宽，不应写成“原文只自适应中心” |

Gao 文中 DME 脉冲可建模为

\[
 j(t)=A\{e^{-\alpha(t-t_0)^2/2}
       +e^{-\alpha(t-t_0-\Delta)^2/2}\}
       e^{j(2\pi f_c t+\phi)},\quad
 \alpha=4.5\times10^{11}\ {\rm s}^{-2},\quad\Delta=12\,\mu s.
\]

单脉冲幅度半高全宽约 3.5 μs。**3.5 μs 脉宽、12 μs 脉冲对间隔和本方案 12 μs 平滑窗是三个不同参数。** 重叠脉冲不能用彼此独立的单脉冲消隐结果简单相加。

对孤立高斯脉冲，其功率谱包络正比于

\[
 e^{-4\pi^2(f-f_c)^2/\alpha}.
\]

所以 DME 具有不可忽略的有限带宽，不是一个纯 CW。理想矩形陷波仅去掉 \(|f-f_c|\le B/2\) 时，孤立脉冲剩余能量比例为
\(\operatorname{erfc}(\pi B/\sqrt{\alpha})\)。B=400、600 kHz 时，对应约 20.9、41.5 dB 的能量抑制；实际 FIR 的过渡带也会衰减带外能量，因此结果可更高。脉冲对的谱干涉、重叠及实际射频链路会改变详细结果。

## 3. TF_Blanker_v1：固定中心、固定带宽

### 3.1 推荐主方案：复数线性相位 FIR

从实对称低通原型 \(l[n]\) 构造单侧复数带阻：

\[
\begin{aligned}
 L_h&=2D+1,\\
 h[n]&=\delta[n-D]-l[n]\,
       e^{j2\pi f_c(n-D)/f_s},\quad 0\le n< L_h,\\
 H(e^{j\omega})&=e^{-j\omega D}
       [1-L_0(\omega-\omega_c)].
\end{aligned}
\]

这里 \(L_0\) 为去掉线性相位后的实低通响应。通带具有统一 D 样本延迟，补偿后无频率相关的支路相位差。调制指数必须以 \(n-D\) 为原点；直接改成 n 而不调整相位，会破坏与中心冲激的相消关系。

初始参数：

| 参数 | 400 kHz 基准候选 | 600 kHz 强抑制候选 |
|---|---:|---:|
| 中心 | -450 kHz | -450 kHz |
| 深阻带总宽 | 400 kHz | 600 kHz |
| 单侧过渡带 | 150 kHz | 150 kHz |
| 抽头数 | 641 | 641 |
| Kaiser 参数 β | 5.65326 | 5.65326 |
| 低通原型截止频率 | 275 kHz | 375 kHz |
| 固定群延迟 | 320 样本，12.8 μs | 相同 |
| 网格实测最差阻带幅度 | -59.20 dB | -59.71 dB |

这里约 60 dB 是原型设计目标，不是已经保证的严格下限：400 kHz 候选最差值为 -59.20 dB。若验收要求“所有阻带点不高于 -60 dB”，需继续优化抽头数或等波纹原型，并重新验收，而不能把本结果取整后宣称达标。

复 IQ 中 +f 和 -f 是不同频率，不需同时挖掉 \(\pm f_c\)。单个实系数双极点陷波会形成镜像频带损失。验证已确认本 FIR 深零点位于 -450 kHz，而 +450 kHz 的幅度变化仅约 -0.00049 dB。

641 抽头直接逐点卷积在 25 MHz 下代价较大，建议实现阶段比较 overlap-save FFT FIR 与 MEX FIR；不得假设 MATLAB 直接卷积已经满足实时处理。每块需要保留历史和未来对齐所需数据，不能把每个跟踪毫秒单独 FFT、乘掩码再无重叠 IFFT。

### 3.2 对照方案：固定复单极点 IIR

定义 \(q=e^{j2\pi f_c/f_s}\)，取

\[
 H(z)=\kappa\frac{1-qz^{-1}}{1-rqz^{-1}},
 \quad \kappa=\frac{1+r}{2},\quad 0<r<1,
\]

\[
 y[n]=\kappa x[n]-\kappa qx[n-1]+rqy[n-1].
\]

κ 使距陷波中心半个采样周期的频率处增益为 1。若 B 表示完整 -3 dB 带宽，则该归一化下

\[
 t=\tan\!\left(\frac{\pi B}{2f_s}\right),\qquad
 r=\frac{1-t}{1+t}.
\]

窄带近似为 \(r\approx1-\pi B/f_s\)，与 Ferrara 的带宽关系一致。25 MHz / 400 kHz 下 r=0.9509567815，两个带边的实测增益均为 -3.0103 dB。极点包络相对衰减 60 dB 约需 138 样本，即 5.52 μs；这仅是包络衰减尺度，不能作为零状态瞬态完全消失的保证。

IIR 的深零点只在中心，±200 kHz 边缘仍有一半功率通过。对本轮 DME 模型，整段 IIR 的干扰能量抑制只有 9.84 dB。增大带宽、级联多个陷波可增加抑制，但同时增加 GNSS 频谱损失、相位畸变和状态管理复杂性。多极点结构应以 DME 总能量与 GNSS 相关损失联合优化，不能只追求一个频点的零点深度。

### 3.3 如何评价频域损失

对于静态滤波、已补偿公共线性延迟、归一化 GNSS PSD \(G_s(f)\)，相关器的理想 SNR 比可写为 [2]：

\[
 \eta=\frac{\left|\int H(f)G_s(f)\,df\right|^2}
             {\int |H(f)|^2G_s(f)\,df},
 \qquad \int G_s(f)\,df=1.
\]

本轮用采样带内归一化 BPSK sinc² 包络近似 B2a 扩频谱，400 kHz FIR 和 IIR 的连续滤波损失分别约 0.247、0.288 dB。此值用于静态结构比较；它没有建模实际射频通带、脉冲检测的选择效应和时变混合，不能直接当作 TF 的实测 C/N0 校正量。

## 4. 时间权重：保留软边缘，同时避免原始脉冲泄漏

### 4.1 原始三角卷积方案必须单位和归一化

25 MHz 下，12 μs 三角窗使用 K=150，索引 -K…K，共 301 个样本点、300 个采样间隔：

\[
 g[k]=\frac{\max(0,1-|k|/K)}
            {\sum_{\ell=-K}^{K}\max(0,1-|\ell|/K)},\qquad
 w_0[n]=(g*m)[n].
\]

于是 \(g\ge0,\sum g=1\)，自然得到 \(0\le w_0\le1\)。只做峰值归一化、没有单位和归一化，会使密集脉冲卷积后的权重大于 1；再强行截断将变成另一个非线性规则。

归一化也带来一个问题：短脉冲的 \(w_0\) 峰值未必达到 1。即使陷波支路完全消除了干扰，混合输出仍有

\[
 j_{\rm residual}[n]\simeq(1-w_0[n])j[n].
\]

例如 w=0.8 时，原始支路泄漏决定的幅度残留为 0.2，最多约 14 dB 功率抑制。平滑并不等于已经完整消隐。

### 4.2 推荐的扩展平台与三角软边缘

设滤波器影响半径为 R：FIR 取 D=320；IIR 对照取指定衰减尺度 138。先加一个可配置的脉冲尾部裕量 P，本轮 P=50 样本=2 μs：

\[
\begin{aligned}
 m_d[n]&=\max_{|k|\le R+P+K}m[n-k],\\
 w[n]&=(g*m_d)[n],\\
 z[n]&=x_{\rm aligned}[n]+w[n]\{
            y_{\rm aligned}[n]-x_{\rm aligned}[n]\}.
\end{aligned}
\]

它保证在检测集合再扩展 R+P 的区域内 w=1，外侧以三角窗卷积产生平滑过渡。滤波器展宽的脉冲及阈值以下尾部由此受到处理。2 μs 裕量是本轮工程候选，须随实际脉形、功率和虚警情况复核。

该方案的代价是处理时间占比增大。主仿真中，二值检测占比为 3.580%，平均 FIR 权重为 13.656%，权重非零的时间为 16.015%。这些量含义不同，应分别保存；不能把平均权重继续称作 PB 的 PDC。

三角窗的平滑降低时间边缘突变及频谱扩展，但时间乘法仍然会产生频率混合。任何“滤波支路有深零点，所以最终时变输出也保持同样深零点”的判断都需实测。

## 5. 支路延迟与样本时间基准

### 5.1 FIR 可以精确匹配固定延迟

仅有 FIR 时，原始支路补 D 样本，滤波支路已有 D 样本即可匹配。加上对称时间权重后，还必须等待未来的检测结果。本方案所需前视量为

\[
 L=R+P+2K=320+50+300=670\ {\rm samples}=26.8\,\mu s.
\]

对相同物理输入样本 n：

| 分支 | 本身延迟 | 额外 FIFO | 对外共同延迟 |
|---|---:|---:|---:|
| 原始支路 | 0 | 670 | 670 |
| FIR 支路 | 320 | 350 | 670 |
| 权重计算 | 前视需求 670 | 调度统一 | 对齐同一个 n |

这里的 26.8 μs 是 v1 样本依赖带来的最小公共延迟；FFT 分块调度和 I/O 可能再增加输出等待时间。三角卷积本身需要 6 μs 前视，但加入扩展平台后不能仍把整个模块延迟写成 6 μs。

离线读取器可以预读未来数据、返回与原始 n 对齐的结果；这时输出逻辑样本编号仍为 n，底层文件指针可能已前进到 n+L。接收机记录的是逻辑样本时间，不能直接把这个底层 ftell 当作处理后数据的时间，否则会污染伪距和通道对齐。

### 5.2 IIR 不能靠一个 FIFO 完整匹配频率相关群时延

单极点 IIR 有直接通路，但 \(-d\arg H/d\omega\) 随频率变化，中心零点处相位不可定义。其附近本例群延迟约达 20 样本量级。对原始支路统一延迟某个常数，只能在选定频率或加权意义上对齐，不能同时对齐整个 GNSS 宽带。

可采用相关器加权的等效延迟估计、分数延迟或全通均衡做进一步优化，但必须验证相关峰、DLL S 曲线及载波相位偏差。考虑 S4 监测需求，优先选择固定延迟 FIR 更便于建立可核验的时间和幅度模型。实时路径不使用 filtfilt；本目录的对齐参考函数显式使用未来样本。

### 5.3 状态、边界与重捕获

滤波支路应持续更新或从足够的原始历史精确恢复；不能每个脉冲到来才以零状态启动，也不能每个 1 ms 跟踪块重置状态。对于 FIR，可以用历史/未来 halo 独立算块核心；v2 还需要完全一致的系数时间表。

文件开头历史不足、文件结尾未来不足、seek 后预热不足时，应返回有效样本区间和原因。不能把补零后的边缘当成正常 S4 样本。REACQ 的跳转需要恢复相应绝对样本位置的状态/检查点或重放预热数据；不能延续另一时刻的 IIR/ANF 状态。

本轮用含跨边界事件、137/24799/621/18003/733 样本等不规则块进行 halo 验证，块间最大差异为 \(1.86\times10^{-15}\)。这验证的是 v1 离线参考分块等价性，尚不是生产读取器和 REACQ 的集成验收。

## 6. TF_Blanker_v2：自适应中心，固定配置带宽

### 6.1 首选：原始 IF 谱估计驱动 FIR 中心更新

建议 v2 保留 v1 的 FIR 长度、固定阻带宽度和时间权重，只更新 \(f_c\)。这是一种中心参数自适应陷波，不要求逐样本 LMS。流程为：

1. 在统一绝对样本网格上，从**未经过 TF 的原始 IF**生成固定时长估计帧。初始采用 1 ms，25,000 样本；跟踪码周期长度变化不改变此网格。
2. 同时检查脉冲检测证据、谱峰/谱底比和频带形状。无可信干扰证据时保持上次中心，同时由时间权重决定原始支路输出。
3. 对候选频带，使用脉冲定位后的局部谱或固定帧谱做峰值/超额功率质心估计；合并相邻谱段，拒绝明显多峰混合或过宽结果。
4. 对中心做置信度门控、平滑和步长限制，并检查带边是否落在 Nyquist 区间内。带宽不随估计更新。
5. 在统一系数调度点发布中心、置信度和 generation ID；所有卫星使用同一调度结果。

本轮验证的估计器采用 1 ms Hann 帧、32768 点 FFT、谱峰附近 ±500 kHz 正超额谱质心；要求超阈值样本总数不少于约 0.5 μs，且谱峰/中位谱底超过 100（20 dB）。初次接受直接初始化，后续 EWMA 系数 0.5，每帧最大步长 100 kHz。**这些检测常数仅是强 DME 仿真起点，并未完成虚警率和弱脉冲漏检优化。** 脉冲总样本数条件也不等于已检查连续脉宽。

32768 点 FFT 的频率网格约 763 Hz；补零不把真实分辨率或估计精度自动提升到 763 Hz。短脉冲包络、谱窗和重叠决定信息量。Ferrara 文中的均值加三倍标准差、3 kHz 最小带宽和 10 kHz 合并间隔是其 NBI 实验规则，不直接作为本 DME 模块默认值。

当前四个 RF 组的短段中心变化很小。若后续全段检查仍然稳定，v1 即可作为主实验方案；v2 的价值应通过频率漂移、未知中心或频率切换试验体现，不能默认“自适应一定更好”。

### 6.2 首个脉冲、延迟与系数过渡

无先验中心时，因果系统不能在尚未观测到首个脉冲前知道其中心。可选：

| 策略 | 延迟与行为 | 本项目建议 |
|---|---|---|
| 配置初始中心，估计结果用于后续帧 | 延迟接近 v1；突变后第一个脉冲可能使用旧中心 | 已知 -450 kHz 的这五组优先采用 |
| 缓存整帧，估计后处理同一帧 | 增加约 1 ms 帧等待以及边界 halo；首帧也可重处理 | 未知中心的离线实验候选 |
| 脉冲级缓存后局部谱估计 | 等待脉冲结束与前后文；更接近 Gao 思路 | 后续扩展，需要独立评估稳定性 |

v2 的总延迟必须包括中心估计策略，不能照抄 v1 的 26.8 μs。离线可通过绝对样本中心调度表实现同帧重处理，但应明确这用到了未来信息。

中心变化时，不直接在有能量的 IIR 状态上替换 q，也不忽略 FIR 的历史。建议新旧 FIR 使用同一原始历史并行计算，等待新滤波结果有效，在适合的脉冲间隔/帧边界做固定长度输出交叉渐变；两者抽头数相同，延迟相同。过渡期相当于两个频响的混合，需要单独记录和验收。无干扰且 w=0 时可安全准备新系数，但仍需保证下一次启用时状态有效。

### 6.3 可选研究支线：固定极径、仅更新相位的 IIR ANF

若确需递推 ANF，令 \(q=e^{j\theta}\)、r 固定。对局部冻结参数，输出对 θ 的灵敏度满足

\[
 u[n]=-j\kappa qx[n-1]+jr qy[n-1]+rq\,u[n-1],
 \quad g_\theta[n]=2\Re\{y^*[n]u[n]\}.
\]

可在可信干扰片段内进行有界归一化下降：

\[
 \theta_{n+1}=\operatorname{wrap}\left[
 \theta_n-\mu\,
 \operatorname{clip}\!\left(
 \frac{g_\theta[n]}{\epsilon+\widehat P_x[n]},
 -g_{\max},g_{\max}\right)\right].
\]

需用谱估计粗初始化、保持 r 不变，并在无干扰时冻结。上述是局部灵敏度更新框架，**不是对时变递归滤波器全局收敛和稳定性的证明**；本轮没有实现其自适应闭环仿真。DME 单脉冲仅数微秒，不能假定每次脉冲都允许 LMS 从任意初值收敛。Borio 的可变零点模长检测也不能原样使用，因为这里将零点固定在单位圆上。

### 6.4 已完成的中心估计验证

70 个 1 ms 帧，中心含 ±100 kHz 正弦漂移和第 41 帧的 +180 kHz 跳变；第 21–30 帧无干扰，其余帧采用较高脉冲密度检验估计器：

| 指标 | 结果 |
|---|---:|
| 接受更新的帧数 | 60 / 70 |
| 接受帧的原始中心估计 RMS 误差 | 3.69 kHz |
| 平滑中心 RMS 误差 | 19.25 kHz |
| 无干扰帧更新次数 | 0 |
| 无干扰帧中心是否精确保持 | 是 |

平滑后误差较大反映对快速漂移和跳变的滞后；平滑不能被描述成无代价的精度提升。这个结果仅验证中心估计和冻结逻辑，没有验证动态换系数后的跟踪和 S4。

## 7. 嵌入 SDR 的模块边界与配置设计

### 7.1 PB 与 TF 是同一阶段的互斥策略

~~~mermaid
flowchart LR
  A["原始 IQ + 绝对样本编号"] --> B["IFSource / 前端统一调度"]
  B --> C{"配置 mode"}
  C --> O["off"]
  C --> P["现有 PB"]
  C --> T1["TF_Blanker_v1"]
  C --> T2["TF_Blanker_v2"]
  O --> D["统一时间对齐的 IF"]
  P --> D
  T1 --> D
  T2 --> D
  D --> E["捕获 / 重捕获 / 各卫星跟踪"]
  E --> F["Prompt 与噪声统计"]
  F --> G["C/N0、S4、相位监测"]
  T1 --> M["前端诊断元数据"]
  T2 --> M
~~~

mode 取 off / pb / tf_v1 / tf_v2。这里“与 PB 并行”表示实现位置相同、由配置择一使用，默认不做 PB→TF 串联。若为了科研并行比较输出，应明确创建两条独立实验支路。

未出现新字段时按既有 EnablePB 映射，保证旧配置行为不变。出现显式 mode 时它是唯一策略选择；遗留 EnablePB 只作兼容记录，不能在别处继续触发第二次 PB。捕获、重捕获、跟踪和 IF probe 必须遵守相同的选择规则。

### 7.2 分开定义处理器与读取器

建议的职责契约：

~~~matlab
mitigator = createInterferenceMitigator(settings);
mitigator.reset(reason, absoluteSampleOrigin);
[processed, meta] = mitigator.process(raw, absoluteStartSample);
[tail, meta] = mitigator.flush();

source = createIFSource(fileInfo, settings, mitigator);
[ifBlock, meta] = source.read(numberOfLogicalSamples);
logicalSample = source.tellLogical();
source.seek(absoluteSample, checkpointPolicy);
~~~

处理器负责检测、中心估计、滤波、权重及状态；读取器负责未来预读、固定处理帧、历史缓存、逻辑游标和随机读取。低层 process 在预热/末尾允许返回有效样本数不同；读取器为跟踪层提供“要求 n 个逻辑样本就返回 n 个有效样本，或明确 EOF/无效区间”的契约。不能只套一个同名 mitigate 函数而忽略非因果前视和状态。

meta 至少包含：

| 类别 | 必要内容 |
|---|---|
| 时间映射 | inputOrigin、outputOrigin、validRange、commonLatencySamples、logicalSampleRate |
| 掩码统计 | detectorDuty、meanWeight、meanWeightSquared、weightSupportFraction |
| 滤波状态 | centerHz、固定 widthHz、widthDefinition、taps/radius、coefficientHash、generation |
| 质量状态 | centerConfidence、adaptationAccepted、warmup/EOF/retune 标记、阈值数值与单位 |
| 溯源 | 模式、原配置哈希、前端配置哈希、软件版本、估计帧绝对起点 |

原始 IF 总功率和处理后 IF 总功率可作为前端诊断保存，但不能命名为 GNSS S4 或 C/N0。

### 7.3 多卫星必须共享相同前端结果

当前 [trackOneChannel.m](../../tracking/trackOneChannel.m) 为各通道独立 fread，码周期块长会变化，并可能在 parfor worker 内运行。如果简单在每个卫星通道 new 一个 ANF，其估计起点、状态和系数序列会不同，同一物理时刻就可能有多份不同的“处理后 IF”。

优先架构是：公共前端按绝对样本网格只处理一次，再由各通道读取共享结果/缓存。v1 FIR 也可以通过固定 halo 重复计算得到一致结果，但有重复算力开销；v2 至少必须共享中心估计和系数时间表、检查点规则。跟踪模块只消费 IF 和质量信息，不包含陷波器方程。

不宜无条件保存五组完整复 double IF：复 single 在 25 MHz 下已达 200 MB/s，715 s 约 143 GB/组（十进制），尚未包括元数据和原始文件。应比较分块缓存、按需重算与一次处理后的可复用磁盘缓存；写回 int16 则必须额外验证幅度缩放、饱和和再量化噪声。

## 8. S4 与 C/N0：处理位置正确还不够

### 8.1 监测入口保持在相关器之后

正确数据链是：

\[
 {\rm raw\ IF}\rightarrow{\rm TF}\rightarrow
 {\rm correlation/tracking}\rightarrow I_P,Q_P
 \rightarrow I_P^2+Q_P^2,\ C/N_0,\ S_4.
\]

已有跟踪代码在 PB 后调用相关器，再把 pilot Prompt 和 C/N0 送入 scint_calculator。新模块应替换这一前端阶段，不应将 IF 幅度方差直接当成 S4。

无干扰时 w=0，经过时间对齐后输出可以逐样点等于原始输入。不过“物理上没有干扰”不保证检测器永远无虚警。本轮低阈值高斯噪声测试在 200 万样本中出现 1 个超限样本，扩展后权重非零占 0.06695%；五组中的无 DME 文件使用更高的继承阈值，所抽三个片段均未触发。

对于复高斯噪声 \(E|n|^2=\sigma^2\)，单样本理论虚警概率为 \(e^{-T_P/\sigma^2}\)。实际 IF 带限、AGC、量化及脉冲尾部会使样本相关，不能用独立样本模型直接预测完整事件虚警率。

### 8.2 两个支路的噪声相关，权重会调制有用信号

对常量 w，混合通道为 \((1-w)+wH(f)\)，噪声 PSD 与

\[
 N_0 |(1-w)+wH(f)|^2
\]

成正比，包含交叉项。两路由同一份 IF 得到，不能当作独立噪声，只用 \((1-w)^2+w^2|H|^2\) 估算。

时间权重和中心更新使通道时变。即便输入无闪烁，每毫秒有效 Prompt 增益变化也可能产生伪 S4。将该毫秒的线性处理算子暂记为 \(T_k\)，本地码为 c，可计算辅助量

\[
 A_k=\frac{c^H T_k c}{c^Hc},\qquad
 {\rm Var}(n_P\mid T_k)\approx
 \sigma^2\frac{\|T_k^Hc\|^2}{(c^Hc)^2}.
\]

这是冻结掩码/系数后的建模关系。由于掩码本身由带噪声数据决定，条件噪声分布存在选择效应；不是可以未经校准直接代入最终 S4 修正的精确结论。

建议先保存原始后处理 Prompt 指标与前端占空统计，通过已知真值注入验证后再提供增益校正版本。接近零的有效增益不可直接相除放大噪声。现有基于普通 1 ms 热噪声近似的 S4 修正，需要重新验证在有色、非平稳残余干扰下的偏差。

TF 后的 C/N0 应明确为该处理链下的有效估计。抑制后干扰功率降低、估计器偏差降低和真实 GNSS 信噪性能改善是相关但不同的量。不可把 IF 频谱下降 30 dB 写成 C/N0 提高 30 dB。

## 9. 已完成的仿真和 RF 结果

### 9.1 实验条件与指标

MATLAB R2026a，通过已连接 MCP 串行执行。固定随机种子 20260930。主仿真 80 ms，25 MHz，使用本接收机 PRN 11 B2a pilot 主码、理想码对齐，复高斯噪声 RMS=50，输入目标 48 dB-Hz；DME 名义 2700 对/s，实际生成 201 对，峰值为幅度阈值的 20 倍，中心 -450 kHz。未模拟导航数据、二级码同步、载波动态和闭环捕获/跟踪。

用混合 IF 检测一次掩码，再将相同掩码及系数分别施加于已知的有用信号、噪声和干扰分量：

- IR：输入/输出干扰分量总能量比，dB；首尾各 1 ms 不统计。
- 等效 C/(N+J)：理想已知码的 1 ms Prompt 功率比再除以积分时间，dB-Hz。它是本实验代理指标，不是现有接收机 C/N0 估计器的输出。
- 有用强度 CV：无闪烁有用分量经处理后，逐毫秒 Prompt 强度的标准差/均值；反映前端引入的调制，不是正式 S4。

| 2700 / -60 dBm | 22.53 | 23.76 | 24.31 |

这些数字包含噪声与 GNSS，不能称为真实干扰分量 IR。仅看中心 ±200 kHz 时，400 和 600 kHz 都已接近噪声底，差异很小；扩展到 ±600 kHz 才能看见 400 kHz 方案的两侧残留。这说明评价带宽不能只覆盖已经挖掉的中心区。

无 DME 的三个片段均无检测，TF 输出逐样点等于原始数据。四个干扰组的前端平均权重约 8.3%–19.0%，明显高于二值检测占比。远离陷波的所测频带（距中心 >1 MHz 且 |f|<8 MHz）总功率变化在本次计算精度下很小，但这不能代替 GNSS 相关器保真度检验。

## 10. 后续实施与验收

### 10.1 先 v1，后 v2

1. 实现 Frontend 配置解析和统一 IFSource，在 off / pb 两种模式下证明与当前结果一致。
2. 接入 v1 FIR、延迟/逻辑样本映射、固定 halo、诊断元数据。先短段捕获与跟踪，再进行长时 A/B。
3. 用同一原始文件、同一时间段、同一原配置比较 off / PB / TF400 / TF600。避免把不同录制文件的不明起点错位当成算法收益。
4. 完成 S4 和 C/N0 校准后，再接入 v2 中心调度、冻结和系数交叉渐变，并增加频漂/频跳压力试验。

### 10.2 可执行验收项

| 层级 | 判据 |
|---|---|
| 数值与时序 | w∈[0,1]，检测平台 w=1；w=0 时原始数据恒等；±频率符号正确；变块长、跨块脉冲、EOF、seek、REACQ 的有效样本与整段参考一致 |
| 滤波器 | 按明确定义测带宽、阻带最坏点、通带纹波、群延迟；用脉冲总能量和带边残留验收，不能只测中心纯音 |
| 自适应 | 无证据不更新；新旧中心/系数过渡无异常；首次事件和频跳恢复时间可量化；所有卫星看到相同处理结果 |
| GNSS 保真度 | 捕获峰、DLL S 曲线、码偏差、载波相位偏差、有效 C/N0、失锁/REACQ 次数与公共样本映射 |
| S4 | 无闪烁真值下测处理引入的伪 S4；已知闪烁真值下测偏差/RMSE；记录前端占比并检查相关性 |
| 长时与性能 | 至少覆盖 150 s 预热及多个 60 s 窗，最终同配置跑完整五组；测吞吐、峰值内存、缓存容量和恢复成本 |

S4 的通过阈值应由研究希望分辨的最小闪烁幅度和重复试验置信区间确定。本次没有提供可支撑统一数值容差的独立真值，因此不虚设“误差小于某值即通过”。现有五组的长时 PB 结果可作为回归基线，但不是 TF 已完成长时验收的证据。
