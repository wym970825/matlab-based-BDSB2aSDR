# IQ 格式与 FIR 延迟对齐验证简报

日期：2026-09-30。结论：int8/int16 × 25/30.69 MHz × 400/600 kHz 的 **8 种组合全部通过独立验证**，补偿后的冲激峰样本偏移均为 0。本轮仅新增实验室脚本和报告，没有修改接收机或原配置，没有运行捕获/跟踪。

## 1. 已确认的配置规则

存储沿用现有双路交织 IQ：I₀,Q₀,I₁,Q₁,…，复数为 I+jQ。int8 每个复样本 2 字节，int16 为 4 字节。读入后转 double，保持原 ADC 数值，不自动归一化；幅度阈值继承该数据集的 PB 配置或显式 TF 覆盖，不按位宽机械缩放。测试文件使用小端，与当前 Windows 数据读取约定一致。

未显式指定抽头数时，以 25 MHz / 641 抽头为基准换算：

\[
D=\max\left(1,\left\lceil320\frac{f_s}{25\times10^6}\right\rceil\right),\quad L=2D+1.
\]

显式配置的合法奇数抽头优先，随后以 D=(L−1)/2 推导延迟。β=5.65326；中心 -450 kHz；深阻带总宽 400/600 kHz；每侧过渡带 150 kHz。时间参数保持微秒定义：K=round(6 μs·fs)，P=round(2 μs·fs)，H=D+P+2K。报告保存取整后的实际时长，不把 670 写成通用常量。

| 采样率 | 默认抽头 L | D | K | P | H | D/fs | H/fs |
|---|---:|---:|---:|---:|---:|---:|---:|
| 25 MHz | 641 | 320 | 150 | 50 | 670 | 12.8000 μs | 26.8000 μs |
| 30.69 MHz | 787 | 393 | 184 | 61 | 822 | 12.8055 μs | 26.7840 μs |

30.69 MHz 下三角窗实际半跨度为 5.9954 μs，尾部裕量为 1.9876 μs，沿用算法报告的四舍五入规则。P 是候选脉冲尾部裕量，不是对任意干扰形状的保证。

## 2. 对齐方法和独立检查

令 b 为要扣除的复带通 FIR，q 为其因果卷积，D 为固定延迟。物理样本 n 对应输出：

\[
z[n]=x[n]-w[n]q[n+D].
\]

请求核心 [a,b] 时读取真实前后各 H 个样本，计算后只返回核心；输出标签仍是 n，不给时间戳加 D/fs 或 H/fs。参考结果独立使用整段直接中心卷积，再显式混合原始/陷波支路；受测方法使用文件读取、FFT 线性卷积与窄带扣除。

- 每个组合读取 48 个打乱顺序的不规则区间，包含 1 样本块、事件边缘、反向读取和重复读取；有效区与整段参考一致。
- IQ 文件写读逐值一致。跳过 3219 个复样本时，int8 对应 6438 字节，int16 对应 12876 字节；不完整复样本偏移和破损 IQ 尾部被拒绝。
- 文件两端 halo 不足的位置原样返回并标记无效；超出 EOF 时短读/返回空，不生成假数据。w=0 的有效位置逐值旁路。
- 冲激检验：因果输出分别延迟 320/393 样本，补偿后偏移均为 0。2 MHz 通带纯音补偿后相位绝对值小于 1.1×10⁻¹⁶ rad，仅用于验证该测试频点的对齐。
- 负对照：故意错开一个样本，最大相对误差为 0.00264–0.00516；不读 halo 为 0.01425–0.02592，均不能通过。

按输入峰值归一化的最大误差为 **2.58×10⁻¹⁵**，低于预设 10⁻¹² 容差。脚本 Code Analyzer 无警告。另检查了 26.123456 MHz 的系数和样本预算计算，以及偶数抽头、越界频带的拒绝行为；该额外采样率没有运行完整文件矩阵或跟踪。

## 3. 抽头换算的频响依据

| 采样率与抽头设置 | 400 kHz 最差阻带幅度 | 600 kHz 最差阻带幅度 |
|---|---:|---:|
| 25 MHz，641 抽头 | -59.20 dB | -59.71 dB |
| 30.69 MHz，显式固定 641 抽头 | -39.61 dB | -39.87 dB |
| 30.69 MHz，自动换算 787 抽头 | -59.15 dB | -59.70 dB |

以上为各深阻带 4001 个频点的数值检查，支持本次抽头换算规则，不能宣称严格满足 60 dB。显式覆盖 641 仍然生效，同时如实记录较弱频响；不偷偷改变用户的覆盖值。其他采样率仍需测量最终频响。

原 int16 DME 门限约 192.74 已高于 int8 复幅度上限 √2×128≈181.02，不能全局复用。本实验 int8 门限取当前 30.69 MHz 默认跟踪配置的约 53.64；int16 取 DME 配置约 192.74。两种位宽交叉到其他采样率只是合成测试，不代表已标定新的 RF 配置。
