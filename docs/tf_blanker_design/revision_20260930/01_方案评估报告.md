# TF_Blanker 方案评估报告（批复修订版）

版本：R3，2026-09-30。适用项目：F:/matlab-GNSSsdr/BDS/B2a。

本轮仅验证方案和修订文档，不修改接收机、既有实验脚本或五组配置，不执行新的单星跟踪。R2 的 64 次带宽比较保留，R3 新增 int8/int16、25/30.69 MHz 的独立文件读取与延迟验证。当前结论是：FIR 的有限邻域对齐方案可继续作为 v1 基础；600 kHz 在指定强脉冲模型下有收益，但尚不足以替代 400 kHz 基准。配套文件为 [算法设计报告](03_算法设计报告.md)、[代码改写计划](02_代码改写计划.md)、[LLM 升级 prompt](04_LLM软件接收机升级Prompt.md) 和 [延迟对齐验证简报](05_IQ格式与延迟对齐验证简报.md)。

## 1. 批复落实与主方案

| 事项 | 修订后的决定 |
|---|---|
| 带宽单位 | 已确认总带宽 400 kHz、单边 200 kHz；删除“单位待确认”作为当前约束 |
| 固定中心 | v1 配置 -450 kHz，使用带符号复基带频率 |
| 脉冲检测 | 直接采用幅度检测 \(|x[n]|\ge T_A\)，沿用已有经验门限；平方比较只是等价实现选项 |
| 输入 | int8/int16 双路交织 IQ；采样率继承配置，不能固定为 25 MHz |
| 主滤波器 | 复 IQ 线性相位 FIR；默认按 25 MHz / 641 抽头换算，显式抽头优先；不声称全局最优 |
| 时间权重 | 扩展平台 + 单位和三角窗软边缘，保留 12 μs 窗 |
| 延迟 | 离线按绝对样本索引对齐，保留有限前后文；不依赖估计互相关峰来补延迟 |
| 性能取舍 | 抑制性能、GNSS 相关保真度与 S4 可信度优先；不要求实时性，不为吞吐量引入多余架构 |
| 400 / 600 kHz | 400 为当前基准，600 为待比较候选；用四组实际 RF 的同一颗卫星跟踪结果判断 |
| v2 | 仅作后续研究，中心自适应、带宽固定；不进入 v1 必须完成的工作 |
| IIR | 不作为 v1 必须实现的支路；保留一个有理论依据的离线备选，不开展无限制结构搜索 |

推荐实施顺序是：先把 v1 的同一样本对齐与完整脉冲覆盖实现正确，再进行带宽比较。600 kHz 是否更好与“FIR 是否可精确补偿固定延迟”是两个独立问题。

### 2.3 新增多随机种子比较

共同参数沿用第 2.1 节；信号为理想对齐 PRN 11，输入 pilot C/N0 设为 48 dB-Hz，复高斯噪声 RMS=50，幅度门限为 192.7391788329。DME 模型为高斯脉冲，α=4.5×10¹¹ s⁻²，脉冲对间隔 12 μs，每对随机载波相位、随机到达。设置 1350/2700 对每秒和峰值/门限比 4/20，共四种**合成条件**，没有把这两个幅度比标定成实测 -50/-60 dBm。

每种条件 16 个独立种子，每次 80 ms，排除首尾各 1 ms；种子为 603101–603164。每次先从信号、噪声和干扰混合数据检测，随后固定同一掩码和权重分别处理已知分量；400/600 kHz 使用完全相同的输入。统计量为理想 1 ms Prompt 的等效 C/(N+J)，并非接收机 C/N0 估计器或闭环跟踪结果。

|---|---:|---:|---:|---:|
| 1350 / 4 | -0.0045 dB | [-0.0180, +0.0091] dB | 5/16 | 0.00739 / 0.00997 |
| 1350 / 20 | +0.1398 dB | [+0.0905, +0.1892] dB | 14/16 | 0.00717 / 0.00965 |

由此把带宽建议细化为：峰值为门限 20 倍时，600 kHz 的平均代理指标改善约 0.14 dB，值得优先考察强干扰实测片段；峰值为门限 4 倍时，两组区间均包含零，没有足够依据认定 600 更优。四组中 600 的有用分量强度 CV 均更大，且平均 Prompt 功率相对 400 额外下降约 0.014–0.026 dB。这里的短时 CV 衡量门控造成的强度调制，不能作为 60 s S4 偏差。**保留 400 kHz 基准和 600 kHz 候选，不在真实单星结果缺失时更改默认带宽。**

### 2.4 对齐与模块边界的新增证据

对两个带宽分别比较直接线性卷积的显式双支路与窄带扣除，按输入峰值归一化的最大误差不超过 1.59×10⁻¹⁵。27 个不规则核心区间以打乱顺序读取，包含 1 样本块及事件边缘；使用 H=670 后，分块与长段参考最大相对误差不超过 2.14×10⁻¹⁶。非零绝对起点、无干扰恒等、文件边缘旁路/无效标记、EOF 短读和流式索引式均通过实验室参考检查。

故意错用一个样本的延迟或省略 halo 时，误差增至约 4.3×10⁻³–1.65×10⁻²，表明检查能区分这些错误。详细记录见 [contract_verification.json](../../../results/tf_blanker_design/review_20260930/contract_verification.json) 和算法报告第 9 节。这验证的是设计公式及内存参考函数，尚未验证生产读取器、捕获起点传播或 REACQ 接入。

### 2.5 IQ 位宽与采样率适配

用户已确认：支持 int8/int16 双路 IQ，默认抽头随 fs 按 25 MHz/641 抽头换算，并允许显式覆盖。I/Q 顺序沿用原读取器，x=I+jQ，每复样本分别为 2/4 字节；读入浮点后不自动归一化，门限继承该数据集配置。

默认 D=ceil(320fs/25 MHz)、L=2D+1（最低奇数长度 3），K/P 由 6 μs/2 μs 取整，H=D+P+2K。30.69 MHz 得到 L=787、D=393、K=184、P=61、H=822。固定 641 抽头时该采样率最差阻带仅约 -39.6/-39.9 dB；换算后恢复约 -59.2/-59.7 dB。显式覆盖仍被尊重，但必须记录实测频响，不能把名义参数当成性能保证。

八种位宽×采样率×带宽组合通过独立文件测试；对齐后冲激峰偏移均为 0，48 个不规则区间相对整段参考的最大误差为 2.58×10⁻¹⁵。该结果补充了 R2 的内存验证，并未接入生产捕获/跟踪。配置取整、门限及复现方法见 [简报](05_IQ格式与延迟对齐验证简报.md)。已解决修订所需的确认项，其余按既有配置与已批复算法执行。

## 3. 新增 IIR 文献评估

### 3.1 Zhu 等（2023）：值得参考，但不是固定窄带深阻带方案

已阅读用户提供的 *An adaptive hybrid blanking algorithm to mitigate the DME pulse interference on BDS B2a receivers*，GPS Solutions 27:164，DOI 10.1007/s10291-023-01495-5。核对了 PDF 第 4–8 页，重点为式 (3)–(7)、Fig. 7–12、Table 1–2。

其陷波器为

\[
 H(z)=\frac{1-z_0z^{-1}}{1-k_\alpha z_0z^{-1}},
 \qquad z_0=e^{j2\pi f_{\rm nf}/f_s}.
\]

作者在时域定位脉冲，估计中心，通过 J/N 选择极点收缩因子 \(k_\alpha\)。其经验拟合为

\[
 k_\alpha=1-\exp(0.017(J/N)_{\rm dB}-2.034).
\]

该模型来自特定的 20 MHz 接收链路、78 组实验和文中 J/N 估计定义。文中还处理了拟合产生异常负值的情形。**不直接把这些系数、极点参数或限幅规则移植到本项目 25 MHz 数据，也不把它称为中心自适应但固定带宽。** 其核心是干扰越强时允许扩大陷波影响范围，优化跟踪结果。

据此修正上一版的结论：400 kHz 单极点 IIR 参数点约 9.84 dB 的结果，仅说明该结构在那组参数和脉冲模型下较弱；不能证明任何 IIR 都不如 FIR。Zhu 的实验说明应在最终跟踪域选择参数，这与本轮采用四组单星比较的方向一致。该论文没有给出本项目所需的软权重支路严格对齐方案，也没有建立本项目 S4 无偏性。

式 (5) 使用带宽近似关系；若后续复现，必须通过实际频响定义和测量带宽，尤其区分是否做通带增益归一化，不能混用 FIR 深阻带宽与 IIR -3 dB 宽度。

### 3.3 不要求实时性后，一个合理的 IIR 备选

可先把 fc 搬到零频，对复数据的 I、Q 使用相同的**实系数高通 IIR 前后向滤波**，再搬回：

\[
 u[n]=x[n]e^{-j\omega_c n},\quad
 v=\operatorname{FB}_{G_{\rm HP}}(u),\quad
 y[n]=v[n]e^{j\omega_c n}.
\]

远离记录边界时，等效频响为
\(H_{\rm eff}(e^{j\omega})=|G_{\rm HP}(e^{j(\omega-\omega_c)})|^2\)。
可用 Butterworth 或椭圆高通原型、SOS 表示，按最终通带纹波与阻带衰减设计。若目标最终衰减 60 dB、通带纹波 0.1 dB，原型应按前后向平方关系分配 dB 指标，而不是直接重复设计同样指标。

这解决了单向 IIR 的频率相关相位延迟问题，但有三个代价：非有限支撑、文件端点处理和分块一致性。任意固定 halo 只能控制误差，不能像 FIR 那样给出严格有限依赖范围；还需按输入幅度上界验证尾部误差。不能直接把复单侧 IIR 系数送进一个未核验的反向实现，并假定得到单侧 \(|H|^2\) 响应。

**决定：v1 直接采用 FIR，IIR 不阻塞主实验。** 如以后仍想比较，只保留上述离线 IIR 一个备选，在相同阻带/通带指标、脉冲覆盖策略和跟踪评价下检验；若没有明确的抑制或监测优势，停止该分支。无需为 IIR 增加复杂全通均衡、逐样本梯度学习或多级参数搜索。

## 4. 为什么仍选 FIR 作为 v1

这是一项工程与可验证性决定，而不是 FIR 对 IIR 的普遍性能定理：

1. 现有 FIR 已在真实短段上表现出需要的深频带抑制。
2. 有限长度允许严格定义每个输出依赖哪些原始样本，任意分块和 seek 都可精确重现。
3. 固定延迟可代数消去；前端与跟踪之间不需要估计性的群时延补偿。
4. 相同长度的 400/600 kHz 候选具有相同的时间权重和边界预算，便于公平比较。
5. 不要求实时性后，先用简单、可核查的分块卷积即可；优化 FFT 只改变计算方法，不改变算法。

不再要求先建立多进程共享前端服务。v1 是确定性的有限邻域运算，每个卫星私有读取器可以独立得到相同样本；未来确有重复计算压力时再加缓存。v2 才需要共享或可复现的中心系数时间表。

## 5. 四组单星带宽判别实验（待执行）

### 5.1 对照与配置

使用原清单第 2–5 组，优先共同跟踪 **PRN 11**。每组至少比较 PB、TF400、TF600；off 为解释基线，建议同时保留。全长沿用 715000 ms 和原 RF 起点，短测试通过后再跑长记录。本轮尚未启动这些任务。

仅在实验配置副本中设置单星、串行和无需导航输出；采样率、门限、中心、FIR 长度、时间窗、尾部裕量、PLL/DLL/FLL/KF、相干积分和监测设置保持相同。原五份 JSON 不改写。单星不产生正常多星 PVT，实验成功判据不能沿用“至少若干定位点”。

主实验每种模式均通过本模式的前端进行捕获和跟踪。可另加相同初始化状态的短段回放，以隔离捕获差异，但应单独标为受控分析，不替代完整处理链。PRN 11 不可用的情况如实记录，不按每个算法择优更换卫星。

### 5.2 输出与判别顺序

| 层级 | 应比较的内容 | 判别原则 |
|---|---|---|
| 有效跟踪 | 完整率、捕获失败、失锁、REACQ、连续段长度 | 不用删除坏段后的均值掩盖失败 |
| C/N0 | pilot 为主，total 辅助；同物理时间点的配对差值及分布 | 不混用不同估计器或不同分量；报告有效交集及各自覆盖率 |
| 码与载波 | DLL/PLL 鉴别器、码频率和载波连续性、相关峰/S 曲线 | 没有真值时称为内部稳定性或相对偏差，不能称为绝对误差 |
| 强度/S4 | Prompt 强度、前端平均权重、S4 及二者关系 | S4 更低不自动更好；有闪烁时必须保留真实变化 |
| 前端 | 脉冲带内/带边残留、通带影响、异常区间 | 只作为解释跟踪结果的辅助证据 |

C/N0 的统计在共同稳定跟踪时段上进行；S4 沿用现有 150 s 预热、60 s 窗和 5 s 更新，并保存其有效标记。60 s 窗每 5 s 更新高度相关，不能把所有输出当独立样本计算很窄的置信区间。使用按连续时间分块的配对统计/重采样，块长至少覆盖监测窗并检查更长相关性；有限记录得到的区间需报告其不确定性。

不同闭环可能产生略有差异的码周期边界。配对时使用绝对样本对应的文件时间，并保存每个估计窗的实际起止；不能简单按数组行号配对，也不跨失锁段插值。需要严格同窗比较时，可从保存的 Prompt 在共同物理时间网格上用同一估计规则离线复算，并与接收机原生输出分开报告。

独立真值未对齐前，无 DME 文件不是其他四个录制文件的逐时刻 S4 真值。可以对同一段干净 RF 叠加已知 DME 和已知强度变化，增加有真值的接收机级验证，但这是后续实验，不是本轮已有结果。

### 5.3 选择规则预先固定

- 若 600 kHz 的配对 C/N0 改善稳定、置信区间支持正收益，且没有新增跟踪失效、明显码/相位异常或已知真值 S4 退化，可将其升为主候选。
- 若两者差异处于统计不确定范围，优先保留频谱损失较小的 400 kHz，不因前端残留较小就宣布 600 kHz 更好。
- 若不同干扰组存在明确取舍，报告逐组结论；可以为不同场景预先配置不同固定带宽，仍属 v1，但不临时加入在线带宽自适应。
- 缺少 S4 真值时，可确认“跟踪表现更好”的候选，不能同时宣称“闪烁监测无偏”。监测用途的最终采用还需校准证据。

先记录有效覆盖，再作配对比较；不根据结果反复修改门限、尾部裕量和环路参数。若发现这些参数需改变，另开实验轮次。
