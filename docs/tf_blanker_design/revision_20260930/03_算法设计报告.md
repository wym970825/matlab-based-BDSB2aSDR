# TF_Blanker_v1 算法设计报告

版本：R3，2026-09-30。本文是待实现的规范，不表示算法已接入接收机。R3 明确 int8/int16 交织 IQ、配置采样率和抽头换算；独立验证见第 9 节及 [延迟对齐简报](05_IQ格式与延迟对齐验证简报.md)。主方案仍为固定中心、固定带宽的复 IQ FIR，v2 仅作研究扩展。

## 1. 符号、时间基准与设计参数

全文数学索引从 0 开始。原始复采样为 x[n]，n 表示整个 IQ 文件内的复样本编号，不是标量存储元素编号、MATLAB 数组下标或处理块内偏移。v1 接受有符号 int8/int16，均按现有 fileType=2 的 I₀,Q₀,I₁,Q₁,… 交织方式存储，复数约定为 I+jQ。int8 每复样本 Q_b=2 字节，int16 为 4 字节，不能固定按 4 字节换算。读取后转浮点并保留 ADC 数值，不自动按位宽归一化；int16 字节序沿用来源数据约定，当前 Windows/测试文件使用小端。实数单路不属于 TF v1 的输入范围，不改变旧 off/pb 的能力。

\[
 t_{\rm file}(n)=n/f_s,\qquad {\rm byteOffset}(n)=Q_b n.
\]

若文件将来具有头部字节 B_header，则 byteOffset=B_header+Q_b n；当前五组按无头数据处理。skipNumberOfBytes 表示所选数据起点偏移，不自动等同文件头。所有偏移必须按完整复样本对齐。

| 参数 | 符号 | v1 基准 |
|---|---|---:|
| 采样率 | \(f_s\) | 继承配置；25 MHz 为五组实验基准，另验证 30.69 MHz |
| 固定中心 | \(f_c\) | -450 kHz |
| 完整深阻带 | \(B_s\) | 400 kHz，另比较 600 kHz |
| 单侧过渡带 | \(\Delta f\) | 150 kHz |
| FIR 抽头数/延迟 | \(L_h=2D+1\) | 25 MHz 时 641 / D=320；默认按下式换算，显式抽头优先 |
| Kaiser 参数 | β | 5.65326 |
| 幅度阈值 | \(T_A\) | 继承数据集配置；原 int16 DME 组 192.7391788329，无 DME 组 1288.1605785013 |
| 三角窗半跨度 | K | 150 样本，6 μs |
| 脉冲尾部裕量 | P | 50 样本，2 μs，候选值 |
| 检测集合扩展半径 | A | D+P+K=520 样本 |
| 保守前后文半径 | H | A+K=670 样本 |

表中 K/P/A/H 的样本数是 25 MHz 基准值。默认以 L_ref=641、f_ref=25 MHz 换算；若配置提供合法奇数 L_h，则以显式值为准：

\[
L_h=2\max\!\left(1,\left\lceil\frac{L_{\rm ref}-1}{2}\frac{f_s}{f_{\rm ref}}\right\rceil\right)+1,
\quad D=(L_h-1)/2.
\]

\[
K=\operatorname{round}(6\times10^{-6}f_s),\quad
P=\operatorname{round}(2\times10^{-6}f_s),\quad
A=D+P+K,\quad H=D+P+2K.
\]

上式的默认参考抽头/参考采样率与实际输入 fs 分开保存。25 MHz 得到 (L_h,D,K,P,H)=(641,320,150,50,670)；30.69 MHz 得到 (787,393,184,61,822)。显式覆盖后重新推导 D/A/H，不混用默认延迟。换算维持近似物理滤波长度，仍需对新 fs 检查实际频响与 Nyquist 边界；不是所有采样率的性能保证。

三角窗长度为 2K+1，名义端点跨度 12 μs，实际跨度为 2K/fs；尾部名义 2 μs，实际 P/fs。25 MHz 时为 301 点；30.69 MHz 为 369 点、实际跨度约 11.9909 μs，实际尾部裕量约 1.9876 μs。在同一 fs 的 400/600 比较中固定 D、K、P，唯一滤波设计变化为 B_s。2 μs 裕量仍是候选值，没有适用于任意脉冲形状的理论保证。

## 2. 幅度检测

\[
 m[n]=\mathbf 1\{|x[n]|\ge T_A\}.
\]

采用现有经验幅度阈值，保持物理量和字段名称一致。I²+Q² 与 T_A² 的比较在实数精确算术下等价；计算前须转浮点，避免整数乘方溢出。但浮点舍入可能使紧贴门限的合成样本产生不同判决，不能把数学等价写成所有浮点输入的逐位一致保证。v1 以 abs(x)>=T_A 为规范判决；如以后改用平方优化，必须在目标输入格式上验证。无需新建功率门限配置，也不重新估计噪声或引入新的阈值学习。

TF 对一次实验解析出一个 T_A，并在捕获、跟踪、重捕获中一致使用。默认取 PB_settings.Th_static_tracking，缺失时退回 Th_static；这五组两者相同。其他数据若需要不同阈值，应通过明确的 TF 配置覆盖并记录，不隐含依赖调用者所处阶段。旧 PB 模式保持它原有的阈值规则。

门限单位始终对应读入且未归一化的复 IQ 幅度。不能把五组 int16 数据的数值全局复制到 int8：192.74 已高于 int8 的最大复幅度约 181.02。当前 30.69 MHz/int8 默认配置的跟踪门限约 53.64，按该配置继承即可；不按位宽比例或新采样率重复缩放已解析门限。

检测只依赖原始 x；不能对滤波后样本再次检测，不能在 TF 前先 PB。NaN/Inf 或破损 IQ 对应输入错误/无效数据，不能让比较返回 false 后被伪装成“无干扰”。

## 3. 复数 FIR 陷波

### 3.1 原型和系数

设计实对称低通 l[u]，u=0,…,2D，满足 l[u]=l[2D-u]。低通通带覆盖 B_s/2，阻带从 B_s/2+Δf 开始。当前窗函数原型的名义截止点取 B_s/2+Δf/2：

\[
\begin{aligned}
 \omega_c&=2\pi f_c/f_s,\\
 b[u]&=l[u]e^{j\omega_c(u-D)},\\
 h[u]&=\delta[u-D]-b[u].
\end{aligned}
\]

这里 b 是被扣除的窄带分量滤波器，h 是陷波滤波器。若原型去线性相位响应为 L_0，则

\[
 H_{\rm NF}(e^{j\omega})
 =e^{-j\omega D}\,[1-L_0(\omega-\omega_c)].
\]

注意三个实现约束：

- 指数使用 u-D，不能丢掉中心相位因子。
- 系数为复数，不额外添加 +450 kHz 镜像陷波。
- fir1 等函数生成的系数须测频响确认，不能只依据抽头数和 β 宣称严格 60 dB 达标。

### 3.2 与原始样本 n 对齐的输出

先定义因果窄带滤波结果

\[
 q[r]=\sum_{u=0}^{2D}b[u]x[r-u].
\]

通常的因果陷波输出为 \(x[r-D]-q[r]\)。将它按其物理样本时刻对齐，可写成

\[
 y_{\rm NF}[n]=x[n]-q[n+D].
\]

因此最终混合等价于

\[
 \boxed{z[n]=(1-w[n])x[n]+w[n]y_{\rm NF}[n]
              =x[n]-w[n]q[n+D].}
\tag{1}
\]

式 (1) 是推荐的实现核心：先从相同原始数据得到对齐的窄带分量，再按权重扣除。两个表达式在精确算术下相同，可以用它们的数值一致性检验支路对齐。w=0 的位置直接复制原始 x，保证旁路逐样点恒等；避免无效滤波值被“0×NaN”污染。

## 4. 扩展平台与三角软边缘

### 4.1 权重定义

对于整数 K≥1，取

\[
 g[k]=\frac{\max(K-|k|,0)}{K^2},\quad -K\le k\le K.
\]

有 g≥0，Σg=1。对检测集合先扩展：

\[
\begin{aligned}
 A&=D+P+K,\\
 m_d[n]&=\max_{|r|\le A}m[n-r],\\
 w[n]&=\sum_{k=-K}^{K}g[k]m_d[n-k].
\end{aligned}
\tag{2}
\]

由凸组合直接得到 0≤w≤1，无需靠截断制造合法权重。浮点 FFT 计算产生的约机器精度越界可截回区间，截断前超差必须受控；不能用无条件截断掩盖未归一化的错误。

卷积核为三角窗；阶跃平台经过它后，边沿是三角核的累积曲线，呈分段二次形态，不是严格的直线斜坡。

### 4.2 完整滤波平台的证明

设某个检测样本为 s，即 m[s]=1。对满足 |n-s|≤D+P 的任何 n，以及 |k|≤K：

\[
 |(n-k)-s|\le D+P+K=A.
\]

因此 m_d[n-k]=1，进而 w[n]=Σg[k]=1。这证明检测集合扩展 D+P 后的全部样本均被完整滤波。

单个连续检测区间 [a,b] 对应：

| 区域 | 保守边界 |
|---|---|
| 必定 w=1 的平台 | [a-D-P, b+D+P] |
| w 可能非零的全部范围 | [a-D-P-2K, b+D+P+2K] |
| 每个外侧过渡的跨度 | 2K/fs=12 μs |

邻近脉冲的扩展集合自动取并集，重叠部分不能把权重相加到 1 以上。12 μs 的 DME 脉冲对间隔不是拆分事件的硬性规则。

### 4.3 为什么平台需要覆盖滤波器展宽

假设可忽略尾部后的干扰 j_0 支撑在检测集合扩展 P 的范围内。窄带 FIR 对齐后将其支撑再向两侧扩展 D。式 (2) 保证在该范围内 w=1，所以：

\[
 j_0-wB j_0=(I-B)j_0.
\]

也就是说，对这部分干扰，门控后的抑制等于连续执行同一个 FIR 的抑制，不会因为支路混合再引入原始脉冲泄漏。B 表示对齐的窄带 FIR 算子。

真实高斯脉冲不是紧支撑。写成 j=j_0+e，门控输出与连续 FIR 的差值为

\[
 (1-w)Be,\qquad
 \|(1-w)Be\|_2\le\|B\|_{2\to2}\|e\|_2.
\]

因此 2 μs 裕量的充分性取决于被遗漏的尾部能量、检测噪声和脉冲重叠。该界说明如何校验裕量，并不自动证明当前 P 对所有实测脉冲都充分。

### 4.4 操作顺序不能交换

正确运算是
\[
 z=(I-\operatorname{diag}(w)B)x.
\]
不能改成先给输入乘 w 再滤波，即 \(x-B(\operatorname{diag}(w)x)\)。通常
\(\operatorname{diag}(w)B\ne B\operatorname{diag}(w)\)；交换顺序会改变边缘、频谱和滤波器所需历史。

## 5. 延迟补偿的严格方案

### 5.1 区分三种“延迟”

1. **FIR 群延迟 D=(L_h−1)/2 样本**：线性滤波器的确定性索引位移，通过 q[n+D] 精确对齐；25/30.69 MHz 默认分别为 320/393。
2. **前后文预算 H=D+P+2K 样本**：计算权重和滤波所需要的原始数据邻域；25/30.69 MHz 默认分别为 670/822。由 A+K 给出保守充分上界；三角窗端点为零，故不宣称它是不能再减一个样本的严格最小值。
3. **程序输出等待**：读取、分块、磁盘和计算耗时，不进入 GNSS 物理观测时间。非实时离线处理不要求将等待时间最小化。

FIR 对齐分量 q[n+D] 只依赖 x[n-D:n+D]。权重依赖 m[n-H:n+H]，检测又仅依赖同位置 x。故 z[n] 至多依赖 x[n-H:n+H]，因为 H≥D。

### 5.2 推荐的离线区间读取算法

需要输出绝对样本区间 [a,b] 时：

1. 从原始文件读取扩展区间 [a-H,b+H]，记录其绝对起点 ℓ=a-H。
2. 在整个扩展区间计算幅度检测、扩展和卷积权重。
3. 对同一原始扩展区间做线性 FIR 卷积，取与原始局部索引对应的 D 样本对齐结果。
4. 用式 (1) 或等价双支路表达式混合。
5. 只返回核心 [a,b]，长度严格为 b-a+1，outputStartAbs=a。扩展区不重复送入相关器。

局部数组采用 MATLAB 从 1 开始的索引。若绝对样本 n 对应输入数组位置 p=n-ℓ+1，则因果卷积结果中应使用位置 p+D 的 q；核心位置为 H+1:H+(b-a+1)。请求区间两侧各有 H，故核心所需滤波历史/未来和检测历史/未来都存在。

FFT 实现必须是线性卷积；整块 FFT 长度至少为“实际输入长度 + FIR 长度 -1”，或使用经过验证的 overlap-save/add。不得使用无补零的等长 FFT 循环卷积。首版可直接调用成熟的线性卷积函数，待结果通过后再优化。

### 5.3 分块一致性与 seek

式 (1)–(2) 都由原始 x 的固定有限邻域决定。只要相同绝对 n 使用相同阈值和系数，任何分块方式都得到同一个 z[n]，与先前读过哪个块无关。变长度跟踪码周期、重捕获回退、不同卫星起点均可按同一规则读取。

这允许 v1 使用每通道私有文件句柄和读取器，而不必建设多通道共享状态服务。重叠读取会增加一些计算和 I/O，但不改变算法；非实时条件下先接受这种代价。缓存只是优化，其键至少包含输入文件标识、绝对范围和完整前端配置/系数哈希。

不能将 seek 后的滤波器置零、跳过 halo 后仍声称等价；也不能复用某个不相邻时间位置的递归状态。本方案依靠有限邻域重算避免了这两类问题。

### 5.4 若未来采用顺序因果实现

为便于检查，令处理时钟 r 时已有原始输入 x[r]，目标输出物理索引 n=r-H：

\[
 z_{\rm emitted}[r]
 =x[r-H]-w[r-H]q[r-(H-D)].
\]

原始支路延迟 H，因果陷波支路本身延迟 D 后再补 H-D，权重按同一 n 使用。25 MHz 基准为 H=670、D=320、H-D=350；30.69 MHz 自动换算为 H=822、D=393、H-D=429。输出标签仍为 n，不能再给观测时间加 H/fs。

该表达式只是与离线参考等价的流式实现契约，本轮不要求实现。若额外 FFT 分块缓存增加等待，逻辑样本标签依然不变。

### 5.5 文件起止和请求边缘

请求块的边缘与原始文件的边缘必须分开处理。块边缘有真实 halo，可以精确计算；文件起止外没有观测样本，无法证明同样等价。

对于 N 个原始样本，保守完全有效区间为 [H,N-1-H]。请求核心本身位于文件内时，接口保持核心长度并返回逐样本有效标记；若只是所需 halo 越过文件边缘，不能把补零或镜像当成真实 IQ。建议这些上下文不足的核心样本原样返回并标记 boundaryBypass / valid=false，仅供长度与诊断保持；科研指标不使用这些样本。若连请求核心都超出物理文件范围，则按 EOF 短读/终止，不凭空生成所谓“原始旁路样本”。

捕获包装层选择真实有效的连续区间，并记录实际 acqInputStartAbs；必要时多读数据补足捕获时长。它不能把舍弃前 H 点后的数组继续标为文件样本 0。跟踪若遇到无效边界，不将受影响积分标为有效监测结果；结尾按 EOF 终止，不制造额外样本。

若配置从文件内部开始，允许读取该起点之前的真实原始 IQ 作为 halo，但不把 halo 输出给接收机。文件边缘规则仅适用于物理文件边缘，不适用于普通实验起点或跟踪块起点。

## 6. 接收机时间戳、码相位与载波约定

当前接收机常以 ftell/size_per_sample 记录一个码周期开始位置。加入预读后这个值代表底层游标，不能再直接作为 absoluteSample。

新契约：

- source.tellLogical() 返回下一份输出的绝对复样本编号。
- 一次 read(Nreq) 返回从 n0 开始的处理后样本；对应 tick.absoluteSample=n0。
- 底层文件游标可因 halo、预取或缓存处于其他位置，但对外不可改变逻辑编号。
- 捕获返回的 codePhase 若是相对其输入数组、从 1 开始，则跟踪绝对起点为 acqInputStartAbs+codePhase-1。skipNumberOfBytes 已包含在 acqInputStartAbs 时，不得再次相加。
- 保留旧接口时，应在包装层完成该转换，并新增明确的绝对起点字段；不得同时使用旧式偏移公式和新式绝对起点。
- 不把 D/fs 或 H/fs 加入 startOffset，不重复平移 TOW/伪距，不用导航钟差去掩盖前端索引错误。

固定时延匹配只解决实现引入的样本位移。非对称频谱挖除、时间权重与码结构仍可能改变相关峰和鉴别器偏差，必须另行验证。不能由“已对齐 D 样本”推出“码和载波绝对无偏”。

本 FIR 系数在原复基带直接执行，不需要每块重启一个数字混频器。如以后采用搬频实现，混频相位必须由绝对索引生成或连续保持，不能每个跟踪块随意重置。

## 7. 与跟踪解耦的最小模块

~~~mermaid
flowchart LR
  R["原始 IQ 与绝对索引"] --> S["IFSource：区间读取与 halo"]
  S --> M{"Frontend.mode"}
  M --> O["off 原样"]
  M --> P["既有 PB"]
  M --> T["v1：幅度检测、扩展权重、复 FIR、对齐"]
  O --> U["处理后 IF + 逻辑索引 + 有效标记"]
  P --> U
  T --> U
  U --> A["捕获 / 单星跟踪 / REACQ"]
  A --> C["pilot Prompt、C/N0、S4"]
~~~

建议的两个接口层：

~~~text
TFBlankerV1.applyRange(rawWithHalo, rawStartAbs, coreStartAbs, coreLength)
    -> processedCore, metadata

IFSource.readRange(startAbs, count)
IFSource.read(count)
IFSource.seekAbs(startAbs)
IFSource.tellLogical()
    -> processed samples with exact physical indices
~~~

v1.applyRange 是确定性核心，拥有固定系数和已解析门限，不拥有卫星 PRN、DLL/PLL 状态或导航状态。IFSource 管理字节读取、IQ 转换和缓存。off/pb 通过同一选择入口执行，TF 不再调用旧 PB。旧配置缺少 Frontend 时映射原 EnablePB；有显式 mode 时只使用该 mode，记录覆盖信息。

v1 只需要输出 detectorDuty、meanWeight、meanWeightSquared、weightSupportFraction、validCount、boundary 标记、物理起止、系数和配置哈希。统计按实际积分区间核心样本计算，不能包含重复 halo。不必为 v1 实现 adaptive confidence、动态 generation 调度或全局检查点数据库。

## 8. C/N0 与 S4 的有效性要求

处理后的 IF 进入现有相关器，再计算 pilot 强度、C/N0 和 S4。保留已校正的强度定义、预热和热噪声处理；本阶段不改监测公式来“改善结果”。

即使固定 w，两个支路的噪声也相关，其谱由 \(|(1-w)+wH|^2\) 决定；不能假定为两份独立噪声。w 随时间变化又会引入有效信号增益变化，因此逐毫秒记录前端统计与有效性，为解释 S4 变化提供依据。

w=0 的恒等性、无干扰数据的虚警率以及包含真实闪烁的恢复偏差，是三个不同验收问题。硬阈值经软权重包裹后仍可能误触发。一个有效 S4 窗必须满足现有预热要求，并额外满足前端和跟踪的完整性要求；发生间断时按明确规则使窗口无效/重新预热，不能把无效样本填零后当作弱信号波动。

本轮不设计自动按平均权重除法“修正 S4”。这样的修正需要码相关增益、噪声相关性和检测选择效应的验证；先保存原指标和诊断量，避免掩盖算法副作用。

## 9. 数学与数值验收要求

### 9.1 生产实现仍需完成的检查

### 9.3 R3 新增 IQ 文件与多采样率验证

独立脚本生成小型 int8/int16 双路 IQ 文件，对 25/30.69 MHz 与 400/600 kHz 的八种组合逐一验证文件字节映射、48 个不规则区间、反向/重复读取、EOF、旁路及有效边界。对齐输出与独立整段直接卷积参考最大相对误差 2.58×10⁻¹⁵；冲激补偿后峰位置偏移为 0，故意错一个样本或省略 halo 均被识别。

抽头自动换算和显式覆盖分别验证；30.69 MHz 固定 641 抽头时最差阻带约 -39.6/-39.9 dB，换算 787 后约 -59.2/-59.7 dB。门限保持各合成输入所用配置的 ADC 幅度单位。另仅对 26.123456 MHz 检查系数与索引预算，不把它称为完整接收机验证。详见 [验证简报](05_IQ格式与延迟对齐验证简报.md) 和 [结果 JSON](../../../results/tf_blanker_design/iq_alignment_20260930/alignment_verification.json)。该脚本不调用生产捕获、跟踪或 REACQ。

## 10. v2 扩展边界

v2 只研究自适应中心：基于原始 IF、固定绝对帧、置信度不足冻结、带宽固定。先沿用 v1 系数长度与样本接口，再研究中心跳变和旧/新滤波器过渡。

v2 的系数调度应在所有卫星间一致；这时每个通道自行估计中心将失去 v1 的同一样本确定性，必须共享或重放同一调度表。若中心估计使用当前整帧未来数据，应把这部分额外依赖显式加入前视预算，不能直接套用当前采样率下 v1 的 H 界。

目前不实现：逐样本梯度 ANF、按 J/N 自适应带宽、多陷波器数目自适应、基于 S4 反馈改滤波器。IIR 文献备选见 [方案评估报告](01_方案评估报告.md)，不改变上述 v1 规范。
