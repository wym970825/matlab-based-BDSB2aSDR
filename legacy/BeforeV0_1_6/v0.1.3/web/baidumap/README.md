# Baidu Map track UI (JSAPI 4.0)

Generated by `launchBaiduMapTrack` after PVT.

## Coordinate note (China)

- GNSS / SoftGNSS LLA is **WGS84**.
- Baidu Maps tiles and overlays use **BD-09**.
- This page converts with official `BMap.Convertor.translate(points, 1, 5, cb)`  
  (`1` = WGS84, `5` = BD-09). See:  
  https://lbsyun.baidu.com/docs/jsapi?title=jsapi4/guide/concept/coord

## Local files

| file | role |
|------|------|
| `index.html` | map page (AK injected at export time) |
| `track.js` | convert + polyline |
| `track.json` | WGS84 points from `navSolutions` |

## AK

Put browser-end key in `config/BaidumapKey.txt` (gitignored).  
Template: `config/BaidumapKey.example.txt`.

Open `index.html` via browser (file://). If AK restricts referer, add local or use a tiny static server.
